# Open Agent Skills Ecosystem Reference

## Registries & Directories
- **Skills.sh Leaderboard:** https://skills.sh/ — Ranks open agent skills by install count and source repository.
- **AgenticSkills.io:** https://agenticskills.io/ — Browseable directory of `npx skills` compatible packages (including `vercel-labs/skills@find-skills`).

## Trusted Official Publishers
- `vercel-labs/agent-skills` — React, Next.js, web design, composition patterns
- `vercel-labs/skills` — Core `find-skills` discovery skill
- `anthropics/skills` — Frontend design, document processing, skill authoring
- `HKUDS/CLI-Anything` — GUI-to-CLI harness methodology and CLI-Hub
