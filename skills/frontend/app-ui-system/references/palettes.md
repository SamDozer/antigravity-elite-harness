# Curated Application Palettes (App UI System)

Avoid saturated purple-indigo generic slop. Use these battle-tested, high-contrast palette pairings:

### 1. Obsidian & Cool Steel (Default Modern Desktop / Scientific)
- **Canvas / BG:** `#090a0f`
- **Surface 1 (Panels):** `#11131c`
- **Surface 2 (Cards, Dialogs):** `#181b26`
- **Border Subtle:** `rgba(255, 255, 255, 0.08)`
- **Border Strong:** `rgba(255, 255, 255, 0.18)`
- **Text Primary:** `#f1f5f9` (Contrast: 16.5:1)
- **Text Secondary:** `#94a3b8` (Contrast: 7.2:1)
- **Text Muted:** `#64748b` (Contrast: 4.6:1)
- **Functional Accent (Cyan/Teal):** `#06b6d4` / `#0891b2`
- **Success (Emerald):** `#10b981`
- **Warning (Amber):** `#f59e0b`
- **Danger (Rose):** `#f43f5e`

### 2. Deep Slate & Nordic Blue (SaaS & Engineering Tools)
- **Canvas / BG:** `#0b0f17`
- **Surface 1:** `#121824`
- **Surface 2:** `#1a2233`
- **Border Subtle:** `#232d42`
- **Text Primary:** `#f8fafc`
- **Text Secondary:** `#8da2be`
- **Functional Accent (Blue):** `#3b82f6`

### 3. Light Workspace Theme (Clean Paper Contrast)
- **Canvas / BG:** `#f8fafc`
- **Surface 1:** `#ffffff`
- **Surface 2:** `#f1f5f9`
- **Border Subtle:** `#e2e8f0`
- **Text Primary:** `#0f172a` (Contrast: 15.8:1)
- **Text Secondary:** `#475569` (Contrast: 7.5:1)
- **Text Muted:** `#64748b` (Contrast: 4.6:1)
- **Accent:** `#0284c7`
